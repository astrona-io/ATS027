# The Image Build And Runtime Contract

This module develops the Image Build And Runtime Contract. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Interpret build context and Dockerfile instructions.
- Distinguish build-time actions from container startup.
- Explain multi-stage runtime dependencies.
- Evaluate command overrides and process permissions.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
