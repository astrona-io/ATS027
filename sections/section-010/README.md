# Define, build and modify container images

This section covers define, build and modify container images. You will study Image Identity And Distribution, The Image Build And Runtime Contract. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Explain image layers and immutable digests.
- Distinguish tags from exact image identity.
- Trace image retrieval and registry authentication.
- Diagnose image selection and pull failures.
- Interpret build context and Dockerfile instructions.
- Distinguish build-time actions from container startup.
- Explain multi-stage runtime dependencies.
- Evaluate command overrides and process permissions.
