# Image Identity And Distribution

This module develops image Identity And Distribution. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain image layers and immutable digests.
- Distinguish tags from exact image identity.
- Trace image retrieval and registry authentication.
- Diagnose image selection and pull failures.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
