# Finite And Scheduled Application Work

This module develops finite And Scheduled Application Work. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Distinguish a Job from a long-running service.
- Explain completions, parallelism and retries.
- Compare CronJob overlap policies.
- Evaluate deadlines, idempotence and cleanup.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
